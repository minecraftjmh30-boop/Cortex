# Cortex

Cortex is a simple program for hearing your voice commands to do simple tasks

## Installation

Python Version ***3.12 ONLY***

download all dependencies: 

```bash
pip install -e.
```

## For Linux

For Linux use, you need to run this command for the program to use audio

```bash
sudo apt-get update && sudo apt-get install -y portaudio19-dev flac libespeak1 python3-pyaudio
```

linux_fix.py should remove all known errors in the terminal for a cleaner experience
